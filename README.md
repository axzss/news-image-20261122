A newspaper front page — THE WORLD, Sunday 22 November 2026 — summing up
the day: Iran strikes Bahrain as the Gulf crisis deepens, COP31 talks run
into overtime in Antalya, Mexico captures cartel boss 'El Chapo Isidro',
US stocks slide into correction in an AI sell-off, plus the Shenzhen
trilateral, Russia hitting Kryvyi Rih, the EU–Indonesia trade deal and
GTA VI's $3.8bn first-day sales record. Rendered with PIL from a generated
dusk photograph of tankers in the Strait of Hormuz; every fact on the page
was checked against wire reports of 22 November 2026. The program copies
the bundled image to `/output/entry.png`, byte-identical on every run, with
no network access.

## Run it

```sh
python3 main.py --output /output/entry.png
```

To re-render the page from scratch: `python3 render.py` (needs Pillow and
the DejaVu / Liberation / Noto fonts; writes `assets/entry.png`).
